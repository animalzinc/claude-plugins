# Addresses that point nowhere

Every test suite needs a web address that will never reach a real company. The Internet Assigned Numbers Authority (IANA) reserves example.com, example.net and example.org for use in documentation.

IANA sells these domains to companies that ask early, as its [example domains page](https://www.iana.org/help/example-domains) explains.

Tim Berners-Leigh proposed the World Wide Web in 1989, long before anyone needed a safe address for a code sample.
