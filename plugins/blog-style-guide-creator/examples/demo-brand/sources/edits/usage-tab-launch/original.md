# The usage tab is here

## Why We Built It

Most dashboards die quietly — nobody decides to stop using them, they just stop. The usage tab shows when each dashboard was last opened, and by how many people.

In the beta, 30% of workspaces archived at least one dashboard in the first week. Another 12% assigned a new owner to one they kept.

## What It Shows

Sort by last opened and the stale ones rise to the top — the same list every data lead has been meaning to make. The tab is free on every plan and takes 2 minutes to read.
